DATE RANGE FORMATS
------------------

Supported numeric formats include:
- 2026-08-01 to 2026-09-15
- 2026/08/01 to 2026/09/15
- 01-08-2026 to 15-09-2026
- 01/08/2026 to 15/09/2026
- from 2026-08-01 to 2026-09-15
- between 2026-08-01 and 2026-09-15
- 2026-08-01 until 2026-09-15
- 2026-08-01 through 2026-09-15

IMPORTANT
---------
- Period-based highest/lowest questions calculate cow-wise totals across the selected period.
- A 15-day question uses 15 calendar days.
- A 1-month question uses the last 30 days.
- A 2-month question uses the last 60 days.
- A 3-month question uses the last 90 days.
- A 7-day / 1-week question uses the last 7 calendar days.
- A custom date range uses the exact two dates entered.
- Results are based only on milk records currently stored in the portal.

AUTOMATIC ALERT RULES
---------------------
1. Vaccine: alerts when a vaccination record's Next Due date is within the configured warning window (default 7 days).
2. Deworming: alerts when a health record contains deworming/worm information and its Next Due date is within the configured warning window (default 7 days).
3. Feed stock: alerts when stock is at or below the item's Minimum Stock.
4. Delivery: alerts when an Expected Calving date is within the configured warning window (default 30 days).
5. Alerts are cow-wise for vaccine, deworming and delivery records, and item-wise for feed stock.
6. Duplicate alerts are suppressed until the alert condition changes or a manual check is requested.
7. The portal checks automatically while the HTML page is open. For 24/7 alerts when the browser is closed, connect the webhook to a server/automation workflow.
